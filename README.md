# Medieval English Translator

A web application that translates modern English into medieval/fantasy style text using AI.

## Features

- **Medieval Translation**: Convert modern English to archaic, fantasy-style language
- **Multiple Tones**: Choose between default, poetic, or concise styles  
- **Fast AI**: Powered by Google Gemini API for quick responses
- **Clean UI**: Dark medieval-themed interface
- **Copy to Clipboard**: Easy sharing of translations

## Live Demo

[Try it live here!](https://your-medieval-translator.vercel.app)

## Examples

- "Hello there" → "Hail, traveller"
- "How are you?" → "How fare thee this day?"
- "Can you help me?" → "Might thou lend me thine aid?"

## Tech Stack

- **Backend**: Python Flask + Google Gemini API
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Vercel
- **Styling**: Medieval/fantasy theme with dark mode

## Usage

1. Enter modern English text
2. Choose tone (optional)
3. Click "Translate to Medieval"
4. Copy and share your medieval text!

## Local Development

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/medieval-translator.git
cd medieval-translator

# Install dependencies
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt

# Set API key
set GEMINI_API_KEY=your_api_key_here

# Run locally
python backend/app.py
```
